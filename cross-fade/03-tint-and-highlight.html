聚光效果

和明暗图像混合，强调画面中心区域。

核心 CSS

.tint-demo {
  --photo: 72%;
  --overlay: url("assets/warm-overlay.svg");
  background-image: url("assets/forest.svg");
  background-image: -webkit-cross-fade(
    url("assets/forest.svg"),
    var(--overlay),
    var(--photo)
  );
  background-image: cross-fade(
    url("assets/forest.svg") var(--photo),
    var(--overlay)
  );
}
