01 基础滑块

首页 下一页 README

用百分比控制两张图的混合

滑块的值会写入 CSS 自定义属性 --mix。在旧语法里，这个百分比表示第一张图的保留量；第二张图自动使用剩余比例。

50%

核心 CSS

.basic-demo {
  --mix: 50%;
  --fallback-a: .5;
  --fallback-b: .5;
  position: relative;
  background-image: url("assets/city.svg");
}

.fallback-a {
  background-image: url("assets/mountain.svg");
  opacity: var(--fallback-a);
}

.fallback-b {
  background-image: url("assets/city.svg");
  opacity: var(--fallback-b);
}

.crossfade-layer {
  background-image: -webkit-cross-fade(
    url("assets/mountain.svg"),
    url("assets/city.svg"),
    var(--mix)
  );
}

这个交互 demo 使用当前 Chromium/Safari 更常见的旧语法，并用两层普通背景图兜底。标准语法放到第 4 个示例单独讲。
