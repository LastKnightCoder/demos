shape-outside: circle()

使用 circle() 函数定义圆形环绕区域，让文字沿着圆的轮廓排列。

基础圆形 — 左浮动

这段文字会沿着左侧圆形元素的轮廓进行环绕。可以看到文字不再是沿着矩形边界排列，而是紧密贴合圆形的边缘。这种效果在杂志排版中非常常见，尤其是在人物头像旁边配合文字介绍的场景。shape-outside 属性让我们可以轻松实现这种视觉效果，而不需要手动计算每一行文字的缩进。文字会自然地沿着圆形的弧线流动，创造出优雅的排版效果。这是一个非常实用的 CSS 属性，能够大大提升页面的视觉美感。

基础圆形 — 右浮动

当圆形元素右浮动时，文字会从左侧开始，沿着圆形的左边缘进行环绕。这同样是一种常见的排版方式，特别适合在文章右侧放置装饰性图形或者头像的情况。你可以看到文字是如何优雅地绕过圆形区域的，形成自然流畅的阅读体验。每一行文字的右边界都会根据圆形的曲线自动调整，无需任何额外的 JavaScript 计算。

配合 shape-margin 使用

circle(50%) 让文字紧贴圆形边缘环绕，再配合 shape-margin: 20px 在圆形外添加 20px 的间距缓冲区，让文字与圆形之间保持舒适的距离。注意这里没有设置元素的 margin-right，文字与圆形之间的间距完全由 shape-margin 控制。shape-margin 的好处是间距也沿着圆形扩展，而普通的 margin 只能产生矩形间距。对比上面第一个示例（只有 margin-right: 15px），这里的间距更加均匀自然。

语法

/* 基础用法：半径为元素宽高的 50% */
shape-outside: circle(50%);

/* 指定具体半径 */
shape-outside: circle(100px);

/* 指定圆心位置 */
shape-outside: circle(50% at 50% 50%);
shape-outside: circle(50% at center center);

/* 使用关键字 */
shape-outside: circle(closest-side);
shape-outside: circle(farthest-side);
