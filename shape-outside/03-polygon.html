shape-outside: polygon()

使用 polygon() 函数可以定义任意多边形的环绕区域。配合 clip-path 可以让元素的可见形状和文字环绕形状一致。

三角形

三角形是最简单的多边形之一，只需要三个顶点坐标。这里定义了一个顶部居中、底部占满宽度的等腰三角形。文字会沿着三角形的斜边环绕，在顶部时文字几乎占满整行，随着向下移动，文字需要为越来越宽的三角形让出空间。这种效果非常适合用于引导读者视线的设计。多边形的每个顶点使用百分比或具体长度值来定义其在元素内的位置。你可以清楚地看到文字是如何沿着三角形的倾斜边缘流动的。

菱形

菱形由四个顶点构成，分别位于上、右、下、左四个方向。文字从菱形的侧面开始环绕，在中间最宽处退让最多，在上下两端则可以更靠近元素中心。这种形状在装饰性设计中非常受欢迎，特别是用于展示珠宝、钻石等产品时。菱形的对称性让文字的环绕效果看起来非常和谐。注意观察文字行在菱形不同高度处的变化，完美地贴合了菱形的轮廓。文字在上下尖端处可以延伸到更靠近中心的位置。

箭头形状

polygon() 的强大之处在于可以定义任意复杂的形状。这里展示了一个箭头形状，由七个顶点构成。文字会沿着箭头的不规则轮廓环绕，在箭头尖端处文字需要退让，在箭头尾部的凹陷处文字则可以靠近。这种效果在创意网页设计中非常有趣，可以引导用户的视觉焦点。通过精心设计多边形的顶点，你几乎可以创造出任何想要的环绕形状。

星形

星形是一个更复杂的多边形示例，由十个顶点交替在外圈和内圈排列而成。文字会精确地沿着星形的凹凸轮廓进行环绕，在星形的尖角处文字需要退让更多，而在凹陷处文字可以更靠近元素。这种高度不规则的形状展示了 polygon() 函数的强大能力。虽然定义这样复杂的形状需要精确计算每个顶点的坐标，但效果却是令人惊艳的。在实际工作中，你可以使用在线工具来可视化地编辑这些顶点坐标，而不需要手动计算。星形在凹入的地方文字可以嵌入更深。

语法

/* 三角形 */
shape-outside: polygon(50% 0%, 0% 100%, 100% 100%);

/* 菱形 */
shape-outside: polygon(50% 0%, 100% 50%, 50% 100%, 0% 50%);

/* 使用具体长度 */
shape-outside: polygon(0px 0px, 200px 0px, 200px 150px, 0px 200px);

/* 使用 nonzero 或 evenodd 填充规则 */
shape-outside: polygon(nonzero, 50% 0%, 100% 50%, 50% 100%, 0% 50%);

提示：配合 clip-path 使用相同的 polygon 值，可以让元素的可见形状与文字环绕形状一致。
