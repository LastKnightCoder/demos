shape-outside: url() 与渐变

使用图片或渐变来定义环绕形状。浏览器通过图片的 Alpha 通道（透明度）来确定文字环绕的边界。

注意：使用外部图片时必须符合同源策略（CORS）。本示例使用内联 SVG data URI 和 CSS 渐变来避免跨域问题。

使用 SVG 图片定义形状

这个示例使用内联 SVG 作为 shape-outside 的图片源。浏览器会分析图片中每个像素的透明度（Alpha 值），将不透明区域视为形状的一部分。shape-image-threshold 属性设置为 0.5，表示 Alpha 值大于 50% 的区域都被视为形状内部。文字会沿着这个提取出的形状边缘进行环绕。使用图片定义形状的最大优势是可以创建任意复杂的不规则形状，比如人物轮廓、树叶形状等。

使用 CSS 渐变定义形状

除了图片，你还可以直接使用 CSS 渐变来定义 shape-outside。这里使用了一个径向渐变，中心50%为不透明，外围为透明。浏览器会根据 shape-image-threshold 的值来判断渐变中哪些区域属于形状的内部。这种方式的好处是不需要额外的图片资源，完全在 CSS 中完成。渐变可以创建平滑的过渡效果，配合不同的 threshold 值可以调整形状的大小。这是一种非常灵活且高效的方式来定义环绕形状。

复杂曲线形状

这个示例展示了使用 SVG 路径创建复杂曲线形状的能力。通过贝塞尔曲线，我们可以定义任意复杂的有机形状，这是 polygon() 函数难以实现的。文字会沿着这条平滑的曲线环绕，创造出非常自然的排版效果。这种技术特别适合用于模拟自然形状，如山丘的轮廓、波浪的形态、或者人物的剪影。在实际使用中，你通常会在图形编辑器（如 Illustrator 或 Figma）中设计好形状，然后导出为 SVG 或 PNG 来使用。SVG 的优势是可以缩放而不失真，而 PNG 则可以包含更复杂的半透明渐变效果。注意这里的曲线是如何优雅地引导文字流动的方向的。

语法

/* 使用外部图片 */
shape-outside: url('shape.png');

/* 使用内联 SVG */
shape-outside: url('data:image/svg+xml,...');

/* 使用 CSS 渐变 */
shape-outside: linear-gradient(to right, black 50%, transparent 50%);
shape-outside: radial-gradient(circle, black 50%, transparent 50%);

/* 设置 Alpha 通道阈值 */
shape-image-threshold: 0.5; /* 0.0 到 1.0 */
