shape-outside: inset()

使用 inset() 函数定义一个内嵌的矩形环绕区域，可以为矩形指定圆角。这在需要文字更靠近浮动元素时非常有用。

基础 inset — 四边内缩 10px

inset() 函数从元素的各边向内缩进指定的距离来定义环绕形状。这意味着文字可以比元素的可见边界更靠近元素。在这个示例中，环绕形状比元素本身向内缩了 10px，所以如果没有 margin 的影响，文字实际上可以覆盖到元素边缘的 10px 区域。inset 的值遵循类似 padding 的简写规则：一个值表示四边相同，两个值表示上下和左右，四个值分别表示上右下左。这种方式提供了非常精确的控制。

带圆角的 inset

inset() 最强大的特性是可以通过 round 关键字指定圆角。这让你可以创建圆角矩形的环绕形状。在这个示例中，元素有 30px 的 border-radius，同时 shape-outside 也使用了相同的圆角值，使得文字环绕形状与元素的可见形状完美匹配。文字会沿着圆角的弧线环绕，而不是沿着方形的边角。这种效果在卡片式设计中特别有用，可以让文字和圆角卡片之间产生更自然的关系。注意角落处文字的排列方式。

inset + round 50% 模拟圆形

使用 inset(0px round 50%) 配合 border-radius: 50% 可以创建圆形环绕效果，这是 circle() 的另一种写法。这里同时使用了 shape-margin: 10px 来增加文字间距。inset 配合大圆角值的优势在于：你可以先用 inset 缩小形状区域，再用 round 指定圆角，两步操作独立可控。在某些场景下，这种组合比直接用 circle() 或 ellipse() 更容易微调文字与元素的相对位置。

语法

/* 四边统一内缩 */
shape-outside: inset(10px);

/* 上下和左右分别设置 */
shape-outside: inset(10px 20px);

/* 四边分别设置 */
shape-outside: inset(10px 20px 30px 40px);

/* 添加圆角 */
shape-outside: inset(10px round 20px);

/* 非对称圆角 */
shape-outside: inset(10px round 20px 30px 40px 50px);

/* 使用百分比 */
shape-outside: inset(5% round 50%);
