shape-outside: ellipse()

使用 ellipse() 函数定义椭圆形环绕区域。与 circle() 不同，椭圆有两个半径参数（水平和垂直），可以创建更丰富的环绕效果。

水平椭圆

这是一个宽度大于高度的水平椭圆。文字会沿着椭圆的边缘环绕，在椭圆的上下区域，文字可以更靠近元素中心，而在左右两侧则会被推得更远。水平椭圆适合用于横向展示的图片或装饰元素，能够创造出宽阔、平缓的环绕效果。注意观察文字在不同高度处与椭圆的距离变化，这正是椭圆形状的魅力所在。这种形状在需要展示横幅图片或者宽屏素材时特别有用。

垂直椭圆

这是一个高度大于宽度的垂直椭圆，放置在右侧。文字从左边开始，在靠近椭圆中部时需要更多的退让空间，而在顶部和底部区域文字可以更靠近元素。垂直椭圆非常适合用于竖向的人物照片或者纵向展示的产品图。这种环绕效果让页面看起来更加生动有趣。你可以发现在椭圆的中部，文字行的宽度最窄，而在顶部和底部区域行的宽度则较宽。这种自然的流动感为页面增添了优雅的视觉节奏，让阅读体验更加舒适。文字自然地随着椭圆的轮廓流动，不需要任何额外的代码来计算位置。

圆形 + shape-margin 间距

这个示例将 ellipse(50% 50%) 配合 shape-margin: 15px 使用。ellipse 的半径匹配元素的可见边界，而 shape-margin 在形状外额外添加了 15px 的间距，让文字与椭圆边缘保持舒适的距离。这种组合方式是实际开发中最常用的做法——先用 ellipse() 精确定义形状，再用 shape-margin 微调文字与形状之间的距离，兼顾视觉准确性和阅读舒适度。

语法

/* 基础用法：水平半径和垂直半径各 50% */
shape-outside: ellipse(50% 50%);

/* 指定具体半径 */
shape-outside: ellipse(120px 80px);

/* 指定椭圆中心位置 */
shape-outside: ellipse(50% 50% at 50% 50%);

/* 使用关键字 */
shape-outside: ellipse(closest-side farthest-side);
