📂 目录选择器

showDirectoryPicker() 用法

选择一个文件夹，浏览其中的文件和子目录。

代码示例

// 基本用法 - 只读模式
const dirHandle = await window.showDirectoryPicker();

// 读写模式
const dirHandleRW = await window.showDirectoryPicker({
  mode: 'readwrite'
});

// 遍历目录内容
for await (const entry of dirHandle.values()) {
  if (entry.kind === 'file') {
    console.log('文件:', entry.name);
  } else if (entry.kind === 'directory') {
    console.log('目录:', entry.name);
  }
}

// 获取特定文件
const fileHandle = await dirHandle.getFileHandle('readme.txt');

// 获取子目录
const subDir = await dirHandle.getDirectoryHandle('src');

// 创建新文件 (需要 readwrite 权限)
const newFile = await dirHandle.getFileHandle('new.txt', { create: true });
