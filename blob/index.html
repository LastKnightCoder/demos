JavaScript Binary Data

Blob API 交互式学习示例

Blob 表示不可变的原始数据块，常用于文件下载、图片预览、流式处理、Worker 脚本、上传二进制内容等场景。 这些示例都可以直接打开，不需要安装依赖。

开始基础示例 查看 README
01

创建与读取 Blob

演示 new Blob()、text()、arrayBuffer()、bytes()、stream() 的基础语法。

 02

对象 URL 与下载

用 URL.createObjectURL() 预览和下载文本、JSON、SVG Blob，并正确释放 URL。

 03

File、预览与 slice

File 是 Blob 的子类。本示例读取用户选择的文件，并用 slice() 截取片段。

 04

大 Blob 与流式读取

生成 CSV 数据，比较一次性读取与 blob.stream() 分块读取时的行为差异。

 05

Worker 与 fetch

从字符串 Blob 创建 Worker 脚本，并通过 fetch(blobURL) 把对象 URL 重新读回 Blob。

 06

Canvas 导出图片 Blob

使用 canvas.toBlob() 生成 PNG/JPEG 图片，完成预览和下载。

建议学习顺序

先理解 Blob 是“数据容器”而不是“文件路径”，再学习对象 URL 的生命周期，最后看流式读取、Worker 脚本和 Canvas 导出这些工程场景。
