image-set() 基本用法

说明：image-set() 函数允许浏览器根据设备像素比自动选择合适的图像。 在普通屏幕(1x)上显示蓝色图像，在高清屏幕(2x)上显示红色图像。

演示效果

代码示例

.basic-image-set {
  /* 回退方案 - 不支持 image-set() 的浏览器 */
  background-image: url("image-1x.png");

  /* -webkit- 前缀版本 */
  background-image: -webkit-image-set(
    url("image-1x.png") 1x,
    url("image-2x.png") 2x
  );

  /* 标准语法 */
  background-image: image-set(
    url("image-1x.png") 1x,
    url("image-2x.png") 2x
  );
}
