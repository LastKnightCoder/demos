image-set() 格式协商

格式协商：使用 type() 函数可以让浏览器根据支持的图像格式选择最佳版本。 浏览器会优先选择它支持的现代格式（如 WebP、AVIF）。

基本格式协商

/* 浏览器会选择它支持的第一个格式 */
.element {
  background-image: image-set(
    url("image.avif") type("image/avif"),
    url("image.webp") type("image/webp"),
    url("image.png") type("image/png")
  );
}

结合分辨率和格式

/* 同时指定格式和分辨率 */
.element {
  background-image: image-set(
    url("image-1x.webp") type("image/webp") 1x,
    url("image-2x.webp") type("image/webp") 2x,
    url("image-1x.png") type("image/png") 1x,
    url("image-2x.png") type("image/png") 2x
  );
}
注意：type() 函数的浏览器支持相对较新， 请确保提供适当的回退方案。

常用图像格式 MIME 类型

  • type("image/avif") - AVIF 格式（最佳压缩）
  • type("image/webp") - WebP 格式（广泛支持）
  • type("image/png") - PNG 格式（无损）
  • type("image/jpeg") - JPEG 格式（有损）
