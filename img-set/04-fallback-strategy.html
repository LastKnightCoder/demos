image-set() 回退策略

为确保所有浏览器都能正确显示图像，需要提供完整的回退方案。

演示效果

回退层级

1 基础回退 - 使用普通 url()，所有浏览器都支持
2 -webkit- 前缀 - 支持旧版 Chrome (21-112) 和 Safari (6-16)
3 标准语法 - 现代浏览器使用标准 image-set()

完整代码示例

.element {
  /* 第一层：基础回退 */
  background-image: url("image-1x.png");

  /* 第二层：-webkit- 前缀 */
  background-image: -webkit-image-set(
    url("image-1x.png") 1x,
    url("image-2x.png") 2x
  );

  /* 第三层：标准语法 */
  background-image: image-set(
    url("image-1x.png") 1x,
    url("image-2x.png") 2x
  );
}

CSS 层叠原理

浏览器会按顺序解析 CSS 属性，遇到不支持的语法会忽略该声明，使用上一个有效值。 因此，将回退方案放在前面，标准语法放在最后。
