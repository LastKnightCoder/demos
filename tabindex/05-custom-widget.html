自定义可访问组件 — 标签页（Tabs）

键盘操作：Tab 进入标签栏 → ← → 切换标签 → Tab 进入内容区 → Shift+Tab 返回标签栏
HTML 是网页的结构层。
使用语义化标签（如 <button>、<nav>） 可以让辅助技术正确理解页面内容，减少对 tabindex 的依赖。
CSS 是网页的表现层。
永远不要用 outline: none 移除焦点样式， 应该提供自定义的清晰焦点指示器，保证键盘用户能看到当前焦点位置。
JavaScript 是网页的行为层。
配合 tabindex="-1" 和 .focus()， 可以实现焦点管理、焦点陷阱等高级无障碍交互模式。
