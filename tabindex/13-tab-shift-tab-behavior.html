Tab 和 Shift+Tab 的默认行为

✅ 是的，这是浏览器的默认行为：
  • Tab — 向前移动焦点到下一个可聚焦元素
  • Shift + Tab — 向后移动焦点到上一个可聚焦元素
这是 Web 标准的一部分，所有浏览器都实现了这个行为，无需任何 JavaScript 代码。

3. 焦点循环行为

当焦点到达最后一个可聚焦元素时：

  • 按 Tab：焦点移动到页面的第一个可聚焦元素（包括地址栏、浏览器 UI）
  • 按 Shift + Tab：焦点移动到浏览器 UI（如地址栏、工具栏）
注意：焦点不会自动在页面内循环。如果需要在特定区域内循环（如模态框）， 需要用 JavaScript 实现"焦点陷阱"（Focus Trap）。

4. 焦点陷阱（Focus Trap）示例

在模态框等场景中，需要用 JavaScript 实现焦点循环：

// 焦点陷阱：限制 Tab 键只在模态框内循环
function trapFocus(containerElement) {
  containerElement.addEventListener('keydown', function(e) {
    if (e.key !== 'Tab') return;

    // 获取容器内所有可聚焦元素
    const focusableElements = containerElement.querySelectorAll(
      'a[href], button:not([disabled]), input:not([disabled]), ' +
      'select, textarea, [tabindex]:not([tabindex="-1"])'
    );

    const firstElement = focusableElements[0];
    const lastElement = focusableElements[focusableElements.length - 1];

    if (e.shiftKey) {
      // Shift+Tab：从第一个元素往前，跳到最后一个
      if (document.activeElement === firstElement) {
        e.preventDefault();
        lastElement.focus();
      }
    } else {
      // Tab：从最后一个元素往后，跳到第一个
      if (document.activeElement === lastElement) {
        e.preventDefault();
        firstElement.focus();
      }
    }
  });
}

6. 常见问题

Q: 可以禁用 Tab 键的默认行为吗？

可以，但强烈不推荐。可以用 e.preventDefault() 阻止：

document.addEventListener('keydown', function(e) {
  if (e.key === 'Tab') {
    e.preventDefault(); // 阻止 Tab 键的默认行为
    // 自定义行为...
  }
});

警告：禁用 Tab 键会严重破坏键盘用户的体验，只在特殊场景（如焦点陷阱）中使用。

Q: 可以改变 Tab 键的顺序吗？

可以，有两种方式：

  • 推荐：调整 DOM 顺序，让元素按期望的顺序排列
  • 不推荐：使用正整数 tabindex（难以维护，破坏用户预期）

Q: 移动设备支持 Tab 键吗？

移动设备通常没有物理键盘，依赖触摸交互。但如果连接了外接键盘，Tab 键行为与桌面浏览器一致。

7. 总结

关键要点：
  • Tab 和 Shift + Tab 是浏览器的默认行为，无需 JavaScript
  • 所有现代浏览器都支持，这是 Web 标准的一部分
  • 焦点按 DOM 顺序（或 tabindex 顺序）移动
  • 焦点不会自动在页面内循环，需要 JS 实现焦点陷阱
  • 不要禁用或改变 Tab 键的默认行为，除非有充分理由
  • 优先调整 DOM 顺序，而不是使用正整数 tabindex
