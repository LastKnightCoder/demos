tabIndex 小数值测试

1. HTML 属性设置小数（tabindex="0.5"）

tabindex="0.5"
tabindex="1.9"
tabindex="-0.5"

按 Tab 键，观察这些元素是否可以被聚焦。

2. JavaScript 设置小数

JS: tabIndex = 0.5
JS: tabIndex = 1.9
JS: tabIndex = -0.9

这些元素通过 JS 设置 tabIndex 小数值。
