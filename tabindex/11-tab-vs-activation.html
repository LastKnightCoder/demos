Tab 键 vs 触发点击行为

❌ 错误说法："通过 Tab 聚焦的元素按下 Tab 可触发点击行为"

✅ 正确说法："通过 Tab 聚焦的元素按下 Enter 或 Space 可触发点击行为"

1. 键盘按键的不同作用

按键 作用 说明
Tab 移动焦点 将焦点移动到下一个可聚焦元素，不触发任何操作
Shift + Tab 反向移动焦点 将焦点移动到上一个可聚焦元素，不触发任何操作
Enter 激活/提交 - 按钮：触发点击
- 链接：跳转
- 表单：提交
- 自定义元素：需要手动监听 keydown
Space 激活/选择 - 按钮：触发点击
- 复选框/单选框：切换选中状态
- 下拉框：展开选项
- 自定义元素：需要手动监听 keydown
Escape 取消/关闭 关闭模态框、下拉菜单等
↑ ↓ ← → 导航 在选项之间移动（下拉框、单选框组、自定义组件）

3. 不同元素的键盘激活方式

元素类型 Enter Space 说明
<button> ✅ 触发点击 ✅ 触发点击 原生支持，无需额外代码
<a href> ✅ 跳转链接 ❌ 无效果 链接只响应 Enter
<input type="checkbox"> ❌ 无效果 ✅ 切换选中 复选框只响应 Space
<input type="radio"> ❌ 无效果 ✅ 选中 单选框只响应 Space
<select> ❌ 无效果 ✅ 展开选项 下拉框只响应 Space
<input type="text"> ❌ 无效果 ❌ 无效果 文本输入框不触发点击，Enter 可能提交表单
<textarea> ❌ 无效果 ❌ 无效果 多行文本框，Enter 插入换行
<details> ✅ 展开/折叠 ✅ 展开/折叠 原生支持
自定义元素
<div tabindex="0">		 ❌ 需要手动处理 ❌ 需要手动处理 必须监听 keydown 事件

4. 自定义元素如何响应键盘

如果用 <div tabindex="0"> 实现自定义按钮，必须手动处理键盘事件：

// ❌ 错误：只监听 click 事件
const customButton = document.querySelector('.custom-button');
customButton.addEventListener('click', function() {
  console.log('按钮被点击');
});
// 问题：键盘用户无法激活这个按钮！

// ✅ 正确：同时监听 click 和 keydown 事件
customButton.addEventListener('click', handleActivation);
customButton.addEventListener('keydown', function(e) {
  // Enter 或 Space 键触发激活
  if (e.key === 'Enter' || e.key === ' ') {
    e.preventDefault(); // 防止 Space 滚动页面
    handleActivation();
  }
});

function handleActivation() {
  console.log('按钮被激活');
  // 执行按钮的功能
}
重要：这就是为什么推荐使用 <button> 而不是 <div tabindex="0">。 原生按钮自动处理所有键盘交互，无需额外代码。

5. 常见误区

误区 正确理解
❌ Tab 键触发点击 ✅ Tab 键只移动焦点，Enter/Space 触发点击
❌ 所有元素都响应 Enter 和 Space ✅ 不同元素响应不同按键（见上表）
❌ 添加 tabindex="0" 就能用键盘操作 ✅ 还需要监听 keydown 事件处理 Enter/Space
❌ 链接响应 Space 键 ✅ 链接只响应 Enter 键
❌ 复选框响应 Enter 键 ✅ 复选框只响应 Space 键

6. 无障碍最佳实践

  • 使用语义化 HTML： <button> 自动支持 Enter 和 Space，无需额外代码
  • 自定义元素必须处理键盘： 监听 keydown 事件，响应 Enter 和 Space
  • 不要只监听 click： click 事件不会被键盘触发（除非是原生按钮）
  • 测试键盘访问性： 实际用键盘测试，确保所有功能都可以通过键盘操作
  • Space 键要 preventDefault： 防止 Space 键滚动页面 
// 完整的自定义按钮示例
const customButton = document.querySelector('.custom-button');

// 处理鼠标点击
customButton.addEventListener('click', activate);

// 处理键盘激活
customButton.addEventListener('keydown', function(e) {
  if (e.key === 'Enter' || e.key === ' ') {
    e.preventDefault(); // 防止 Space 滚动页面
    activate();
  }
});

function activate() {
  console.log('按钮被激活');
  // 执行按钮的功能
}

7. 总结

关键要点：
  • Tab 键的作用是移动焦点，不触发任何操作
  • Enter 和 Space 键用于激活元素（触发点击、提交等）
  • 不同元素响应不同的激活键（按钮响应 Enter+Space，链接只响应 Enter，复选框只响应 Space）
  • 自定义元素必须手动监听 keydown 事件处理键盘激活
  • 优先使用语义化 HTML（<button>），避免自己实现键盘交互
