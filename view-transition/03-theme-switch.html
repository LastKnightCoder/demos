点击右上角的开关切换主题。过渡使用 clipPath 圆形扩展动画： 从点击位置开始，新主题如墨水扩散般覆盖整个页面。这通过在 transition.ready Promise 中使用 Web Animations API 实现。

核心实现原理

在 transition.ready 回调中，对 ::view-transition-new(root) 伪元素应用 clip-path 动画，从点击坐标扩展到覆盖全屏的圆形。

用户体验优势

与传统的瞬间切换相比，圆形扩展动画给用户一种"意图延续"感——视觉焦点从操作点向外辐射，符合直觉预期。

UX Pattern
// 获取点击坐标，计算到最远角的距离
const x = event.clientX, y = event.clientY;
const radius = Math.hypot(
  Math.max(x, innerWidth - x),
  Math.max(y, innerHeight - y)
);

// 在 ready 后对新快照应用 clip-path 动画
transition.ready.then(() => {
  document.documentElement.animate(
    { clipPath: [
      `circle(0px at ${x}px ${y}px)`,
      `circle(${radius}px at ${x}px ${y}px)`
    ]},
    { duration: 600, pseudoElement: '::view-transition-new(root)' }
  );
});
