📚 核心技术要点

1. 逻辑单位的使用

  • ch - 字符宽度单位（基于 "0" 字符宽度）
  • lh - 行高单位（基于元素的 line-height）
  • % - 相对于父元素的百分比

2. 约束设置的重要性

  • 始终设置 min-width/min-height 防止元素过小
  • 始终设置 max-width/max-height 防止布局破坏
  • 使用 resize: none 防止手动调整大小

3. 浏览器兼容性处理

@supports (field-sizing: content) { textarea { field-sizing: content; min-height: 3lh; max-height: 20lh; } } @supports not (field-sizing: content) { textarea { height: 100px; resize: vertical; } }
