🎯 inert 属性基础演示

什么是 inert？

inert 是一个 HTML 全局属性，用于使元素及其所有后代元素变为"惰性"状态。 惰性元素无法被聚焦、点击或与之交互，对辅助技术也不可见。

🧪 测试说明

  • 点击切换按钮：观察右侧区域的变化
  • 使用 Tab 键：当右侧区域为 inert 时，Tab 键会跳过所有右侧元素
  • 尝试点击：当右侧区域为 inert 时，所有点击事件都不会触发
  • 视觉反馈：inert 元素会变得半透明（通过 CSS 实现）
  • 屏幕阅读器：如果使用屏幕阅读器，inert 元素会被完全忽略

💡 关键观察点

  • inert 属性会递归应用到所有子元素
  • inert 元素无法通过任何方式获得焦点
  • inert 不会改变元素的默认样式（需要通过 CSS 添加视觉反馈）
  • inert 可以通过 JavaScript 动态切换
