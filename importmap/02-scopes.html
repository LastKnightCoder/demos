Import Maps - 作用域（Scopes）

什么是 Scopes？

Scopes 允许你为不同的 URL 路径指定不同的模块映射规则。这在以下场景非常有用：

  • 不同部分的应用需要使用不同版本的同一个库
  • 微前端架构中，不同子应用有不同的依赖版本
  • 渐进式迁移，新旧代码使用不同版本的依赖

Scopes 工作原理

┌─────────────────────────────────────────────────────────────┐ │ Import Map │ ├─────────────────────────────────────────────────────────────┤ │ "imports": { │ │ "lodash": "/libs/lodash-v4.js" ← 默认映射 │ │ } │ │ │ │ "scopes": { │ │ "/app-v1/": { │ │ "lodash": "/libs/lodash-v3.js" ← /app-v1/ 下的映射 │ │ }, │ │ "/app-v2/": { │ │ "lodash": "/libs/lodash-v4.js" ← /app-v2/ 下的映射 │ │ } │ │ } │ └─────────────────────────────────────────────────────────────┘ 当模块从不同路径导入 "lodash" 时： • /index.js → 使用 /libs/lodash-v4.js（默认） • /app-v1/main.js → 使用 /libs/lodash-v3.js（scopes 覆盖） • /app-v2/main.js → 使用 /libs/lodash-v4.js（scopes 覆盖）

本页面的 Import Map 配置

<script type="importmap"> { "imports": { "helper": "./modules/helper-v2.js", "lodash": "https://cdn.jsdelivr.net/npm/lodash-es@4.17.21/lodash.js" }, "scopes": { "./legacy/": { "helper": "./modules/helper-v1.js", "lodash": "https://cdn.jsdelivr.net/npm/lodash-es@3.10.1/lodash.js" }, "./modern/": { "helper": "./modules/helper-v2.js" } } } </script>

模块解析规则

导入模块的脚本位置 import "helper" 解析为 说明
/index.js ./modules/helper-v2.js 使用默认 imports 映射
./legacy/app.js ./modules/helper-v1.js 匹配 ./legacy/ scope
./modern/app.js ./modules/helper-v2.js 匹配 ./modern/ scope

Scopes 匹配规则

重要：Scopes 的匹配是基于导入模块的脚本 URL，而不是当前页面的 URL。

匹配优先级

  1. 首先检查是否有匹配的 scope
  2. 如果有多个 scope 匹配，使用最具体（最长）的匹配
  3. 如果 scope 中没有定义该模块，回退到顶层 imports
  4. 如果顶层 imports 也没有，则按普通 URL 解析

示例：多层 Scope 匹配

{ "imports": { "lib": "/default/lib.js" }, "scopes": { "/app/": { "lib": "/app/lib.js" }, "/app/admin/": { "lib": "/app/admin/lib.js" } } }

对于 /app/admin/dashboard.js 中的 import "lib"：

  • 匹配 /app/ ✓
  • 匹配 /app/admin/ ✓ （更具体）
  • 最终解析为 /app/admin/lib.js

使用场景示例

1. 微前端依赖隔离

{ "imports": { "react": "https://esm.sh/react@18", "react-dom": "https://esm.sh/react-dom@18" }, "scopes": { "/micro-app-legacy/": { "react": "https://esm.sh/react@17", "react-dom": "https://esm.sh/react-dom@17" } } }

2. 渐进式迁移

{ "imports": { "moment": "https://esm.sh/dayjs" }, "scopes": { "/legacy-modules/": { "moment": "https://esm.sh/moment" } } }

新代码使用 dayjs（moment 的轻量替代），旧代码继续使用 moment。

3. 测试环境 Mock

{ "imports": { "api-client": "/src/api/client.js" }, "scopes": { "/tests/": { "api-client": "/tests/mocks/api-client.js" } } }
