Import Maps - 基本用法

1. 什么是 Import Maps？

Import Maps 允许你在浏览器中使用裸模块说明符（如 import _ from 'lodash'），而不需要构建工具。

本页面使用的 Import Map：

<script type="importmap"> { "imports": { "lodash": "https://cdn.jsdelivr.net/npm/lodash-es@4.17.21/lodash.js", "lodash/": "https://cdn.jsdelivr.net/npm/lodash-es@4.17.21/", "dayjs": "https://esm.sh/dayjs@1.11.10", "uuid": "https://esm.sh/uuid@9" } } </script>
