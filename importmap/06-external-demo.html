外部 Import Map 演示

关键点：外部 Import Map

本页面使用外部 importmap.json 文件！
这是通过 Express 服务器提供的，服务器设置了正确的 MIME 类型：application/importmap+json

HTML 中的引用方式：

<!-- 方式 1：外部 Import Map（需要 Chrome 89+, Firefox 108+, Safari 16.4+）--> <script type="importmap" src="/importmap.json"></script> <!-- 方式 2：内联 Import Map（内容与 importmap.json 相同）--> <script type="importmap"> { "imports": { "lodash": "https://cdn.jsdelivr.net/npm/lodash-es@4.17.21/lodash.js", "dayjs": "https://esm.sh/dayjs@1.11.10", "uuid": "https://esm.sh/uuid@9" } } </script>
注意：外部 importmap（src 属性）需要较新的浏览器版本支持。 本页面使用内联方式，但内容与 /importmap.json 文件完全一致。 你可以访问 /importmap.json 查看文件内容。

服务器端代码

Express 服务器需要为 importmap.json 设置正确的 MIME 类型：

import express from 'express'; const app = express(); // 方式 1：为特定文件设置 MIME 类型 app.get('/importmap.json', (req, res) => { res.type('application/importmap+json'); res.sendFile('importmap.json'); }); // 方式 2：动态生成 Import Map app.get('/dynamic-importmap.json', (req, res) => { const env = req.query.env || 'production'; const importMap = { imports: { "lodash": env === 'development' ? "https://cdn.jsdelivr.net/npm/lodash-es@4.17.21/lodash.js" : "https://cdn.jsdelivr.net/npm/lodash-es@4.17.21/lodash.min.js", "dayjs": "https://esm.sh/dayjs@1.11.10" } }; res.type('application/importmap+json'); res.json(importMap); });
