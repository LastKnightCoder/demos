多个 Import Map 合并演示

浏览器支持说明

多 Import Map 支持：
根据 MDN 文档，浏览器内部维护一个全局的 import map 表示。 当文档中包含多个 import map 时，它们的内容会在注册时合并到全局 import map 中。
注意事项：
  • 多 Import Map 是较新的特性，需要 Chrome 89+, Safari 16.4+, Firefox 108+
  • 如果两个 import map 定义了相同的 specifier，后面的会覆盖前面的
  • 所有 import map 必须在任何 type="module" 脚本之前声明

合并过程示意

Import Map 1
lodash, dayjs
+
Import Map 2
uuid, nanoid
=
全局 Import Map
lodash, dayjs, uuid, nanoid

第一个 Import Map

<script type="importmap"> { "imports": { "lodash": "https://cdn.jsdelivr.net/npm/lodash-es@4.17.21/lodash.js", "dayjs": "https://esm.sh/dayjs@1.11.10" } } </script>

第二个 Import Map

<script type="importmap"> { "imports": { "uuid": "https://esm.sh/uuid@9", "nanoid": "https://esm.sh/nanoid@5" } } </script>

第三个 Import Map（覆盖测试）

<script type="importmap"> { "imports": { "my-greeting": "data:text/javascript,export default 'Hello from Import Map 3!'" } } </script>
这个 import map 使用 data URL 定义了一个内联模块，用于验证合并功能。
