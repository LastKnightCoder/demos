快速开始

启动服务器

要体验完整功能（特别是外部 Import Map），请启动 Express 服务器：

# 安装依赖
npm install

# 启动服务器
npm start

# 或使用开发模式（自动重启）
npm run dev

然后访问 http://localhost:3000
