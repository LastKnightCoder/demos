    使用的库及功能

    1. UUID - 生成唯一 ID

    每个 Todo 项都有一个唯一的 UUID：

    import { v4 as uuidv4 } from 'uuid'; const todo = { id: uuidv4(), // 例如: "9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d" text: "学习 Import Maps", completed: false };

    2. Day.js - 日期处理

    显示 Todo 创建时间：

    import dayjs from 'dayjs'; const createdAt = dayjs().format('YYYY-MM-DD HH:mm:ss'); // 输出: "2024-01-15 14:30:00"

    3. Lodash - 工具函数

    使用 Lodash 进行数据处理：

    import _ from 'lodash'; import orderBy from 'lodash/orderBy.js'; // 统计完成数量 const completedCount = _.filter(todos, { completed: true }).length; // 按创建时间排序 const sortedTodos = orderBy(todos, ['createdAt'], ['desc']);

    4. Nanoid - 短 ID 生成

    生成更短的唯一 ID（可选）：

    import { nanoid } from 'nanoid'; const shortId = nanoid(10); // 例如: "V1StGXR8_Z"

    完整代码结构

    <!-- 1. 定义 Import Map --> <script type="importmap"> { "imports": { "lodash": "https://cdn.jsdelivr.net/npm/lodash-es@4.17.21/lodash.js", "dayjs": "https://esm.sh/dayjs@1.11.10", "uuid": "https://esm.sh/uuid@9" } } </script> <!-- 2. 使用 ES Module 导入 --> <script type="module"> // 像在 Node.js 中一样使用裸模块说明符 import _ from 'lodash'; import dayjs from 'dayjs'; import { v4 as uuidv4 } from 'uuid'; // 你的应用代码... const todos = []; function addTodo(text) { todos.push({ id: uuidv4(), text: text, completed: false, createdAt: dayjs().toISOString() }); } </script>

    优势总结

    • 零配置 - 无需 Webpack、Vite 等构建工具
    • 即时开发 - 修改代码后刷新即可看到效果
    • 标准语法 - 使用标准的 ES Module import 语法
    • CDN 加速 - 利用 CDN 的缓存和分发能力
    • 版本控制 - 在一处集中管理所有依赖版本
