Import Map 重复标识符行为验证

MDN 规则解释

核心规则：第一个定义生效（First Wins）

当多个 Import Map 定义相同的模块标识符时，第一个定义的映射会被保留， 后续的定义会被丢弃。这与 CSS 或 JavaScript 变量的"后者覆盖前者"行为相反。

✅ Import Map 1（生效）

"my-lib" → "version-1.js"

❌ Import Map 2（被忽略）

"my-lib" → "version-2.js"
↓
import "my-lib" → 解析为 "version-1.js"

测试场景

我们定义三个 Import Map，其中有重复的标识符：

标识符 Import Map 1 Import Map 2 Import Map 3 预期结果
greeting "Hello from Map 1" "Hello from Map 2" - Map 1 生效
version "v1.0.0" - "v3.0.0" Map 1 生效
unique-1 "Only in Map 1" - - Map 1 生效
unique-2 - "Only in Map 2" - Map 2 生效
triple "Triple from 1" "Triple from 2" "Triple from 3" Map 1 生效

Import Map 定义

Import Map 1

<script type="importmap"> { "imports": { "greeting": "data:text/javascript,export default 'Hello from Map 1'", "version": "data:text/javascript,export default 'v1.0.0'", "unique-1": "data:text/javascript,export default 'Only in Map 1'", "triple": "data:text/javascript,export default 'Triple from 1'" } } </script>

Import Map 2

<script type="importmap"> { "imports": { "greeting": "data:text/javascript,export default 'Hello from Map 2'", "unique-2": "data:text/javascript,export default 'Only in Map 2'", "triple": "data:text/javascript,export default 'Triple from 2'" } } </script>

Import Map 3

<script type="importmap"> { "imports": { "version": "data:text/javascript,export default 'v3.0.0'", "triple": "data:text/javascript,export default 'Triple from 3'" } } </script>
