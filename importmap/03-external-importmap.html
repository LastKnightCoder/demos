Import Maps - 外部 Import Map

什么是外部 Import Map？

外部 Import Map 允许你将 Import Map 配置放在单独的 JSON 文件中，然后通过 src 属性引用。这样可以：

  • 在多个 HTML 页面间共享同一份配置
  • 更容易进行版本控制和管理
  • 支持动态生成 Import Map
  • 保持 HTML 文件简洁

基本用法

1. 创建外部 Import Map 文件

创建 importmap.json 文件：

{ "imports": { "lodash": "https://cdn.jsdelivr.net/npm/lodash-es@4.17.21/lodash.js", "dayjs": "https://esm.sh/dayjs@1.11.10", "uuid": "https://esm.sh/uuid@9" } }

2. 在 HTML 中引用

<script type="importmap" src="importmap.json"></script> <script type="module"> import _ from 'lodash'; import dayjs from 'dayjs'; // 使用模块... </script>

服务器配置要求

重要：外部 Import Map 需要正确的服务器配置才能工作！

MIME 类型

服务器必须返回正确的 MIME 类型：

MIME 类型 说明
application/importmap+json 推荐的标准 MIME 类型
application/json 大多数浏览器也接受

常见服务器配置

Nginx

location ~ \.importmap$ { types { } default_type application/importmap+json; } # 或者对 .json 文件 location ~ importmap\.json$ { types { } default_type application/importmap+json; }

Apache (.htaccess)

AddType application/importmap+json .importmap # 或者 <Files "importmap.json"> ForceType application/importmap+json </Files>

Node.js (Express)

app.get('/importmap.json', (req, res) => { res.type('application/importmap+json'); res.sendFile('importmap.json'); });

CORS 配置

如果外部 Import Map 托管在不同的域名上，需要配置 CORS 头。
# Nginx add_header Access-Control-Allow-Origin *; # Apache Header set Access-Control-Allow-Origin "*" # Node.js res.setHeader('Access-Control-Allow-Origin', '*');

动态生成 Import Map

可以在服务器端动态生成 Import Map，实现环境切换、A/B 测试等功能：

Node.js 示例

// server.js app.get('/importmap.json', (req, res) => { const isDev = process.env.NODE_ENV === 'development'; const importMap = { imports: { "my-lib": isDev ? "/src/my-lib.js" : "/dist/my-lib.min.js", "lodash": isDev ? "https://cdn.jsdelivr.net/npm/lodash-es@4.17.21/lodash.js" : "https://cdn.jsdelivr.net/npm/lodash-es@4.17.21/lodash.min.js" } }; res.type('application/importmap+json'); res.json(importMap); });

项目结构示例

project/ ├── index.html ├── about.html ├── contact.html ├── importmap.json ← 共享的 Import Map ├── importmap.dev.json ← 开发环境配置 ├── importmap.prod.json ← 生产环境配置 └── src/ ├── main.js └── utils.js

importmap.json

{ "imports": { "lodash": "https://cdn.jsdelivr.net/npm/lodash-es@4.17.21/lodash.js", "dayjs": "https://esm.sh/dayjs@1.11.10", "@/": "./src/" } }

所有 HTML 页面共享配置

<!-- index.html, about.html, contact.html 都使用相同的配置 --> <script type="importmap" src="importmap.json"></script>

注意事项

限制：外部 Import Map 不能与内联 Import Map 同时使用！
<!-- ❌ 错误：不能同时使用 --> <script type="importmap" src="importmap.json"></script> <script type="importmap"> { "imports": { "extra": "/extra.js" } } </script>

其他注意事项

  • 外部 Import Map 文件必须是有效的 JSON
  • 加载外部 Import Map 会阻塞模块脚本的执行
  • 如果外部文件加载失败，所有依赖该 Import Map 的模块都会失败
  • 浏览器会缓存外部 Import Map，注意版本更新时的缓存问题

浏览器支持

注意：外部 Import Map（通过 src 属性）的浏览器支持比内联 Import Map 更晚。
浏览器 内联 Import Map 外部 Import Map (src)
Chrome 89+ 89+
Edge 89+ 89+
Firefox 108+ 108+
Safari 16.4+ 16.4+
