URLPattern 模式语法详解

语法速查表

语法说明示例
:name命名参数，匹配一个路径段/users/:id
*通配符，匹配任意字符/files/*
:name?可选参数/users/:id?
:name+一个或多个段/files/:path+
:name*零个或多个段/files/:path*
:name(regex)带正则约束的参数/users/:id(\\d+)
(regex)匿名正则组/files/(.*).jpg
{text}分组（不捕获）/files{/path}?

1. 命名参数 :name

捕获单个路径段（不包含 /）

const pattern = new URLPattern('/users/:userId/posts/:postId', baseURL);

2. 通配符 *

匹配任意字符（包括 /），结果存储在 groups[0]

const pattern = new URLPattern('/api/*', baseURL);

3. 可���参数 :name?

参数可以存在也可以不存在

const pattern = new URLPattern('/users/:id?', baseURL);

4. 重复参数 :name+ 和 :name*

+ 匹配一个或多个段，* 匹配零个或多个段

const patternPlus = new URLPattern('/files/:path+', baseURL);  // 至少一个
const patternStar = new URLPattern('/docs/:path*', baseURL);   // 零个或多个

5. 正则约束 :name(regex)

使用正则表达式限制匹配内容

const pattern = new URLPattern('/users/:id(\\d+)', baseURL);  // 只匹配数字

6. 分组 {...}

将多个部分组合在一起，常与 ? 配合使用

const pattern = new URLPattern('/api{/v:version}?/users', baseURL);
