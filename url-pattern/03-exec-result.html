URLPattern exec() 返回值详解

exec() 返回值结构

exec() 方法返回一个 URLPatternResult 对象，包含 URL 各组件的匹配信息：

{
  inputs: [string | URLPatternInit],  // 原始输入
  protocol: URLPatternComponentResult,
  username: URLPatternComponentResult,
  password: URLPatternComponentResult,
  hostname: URLPatternComponentResult,
  port: URLPatternComponentResult,
  pathname: URLPatternComponentResult,
  search: URLPatternComponentResult,
  hash: URLPatternComponentResult
}

URLPatternComponentResult 结构

每个组件的结果包含：

{
  input: string,           // 该组件的原始输入值
  groups: {                // 捕获的命名组
    [name: string]: string | undefined
  }
}

实际应用：提取参数

    
const pattern = new URLPattern('/users/:userId/posts/:postId', baseURL);
const result = pattern.exec('https://example.com/users/123/posts/456');

if (result) {
  // 提取路径参数
  const { userId, postId } = result.pathname.groups;
  console.log(userId); // '123'
  console.log(postId); // '456'

  // 提取查询参数（如果模式中定义了）
  const searchParams = result.search.groups;

  // 提取 hash（如果模式中定义了）
  const hashParams = result.hash.groups;
}
