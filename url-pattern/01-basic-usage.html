URLPattern 基本用法

1. 创建 URLPattern

URLPattern 可以通过字符串或对象两种方式创建：

// 方式一：使用完整 URL 模式字符串
const pattern1 = new URLPattern('https://example.com/users/:id');

// 方式二：使用路径 + baseURL
const pattern2 = new URLPattern('/users/:id', 'https://example.com');

// 方式三：使用对象
const pattern3 = new URLPattern({
  protocol: 'https',
  hostname: 'example.com',
  pathname: '/users/:id'
});

2. test() 方法 - 测试匹配

返回布尔值，表示 URL 是否匹配模式。

const pattern = new URLPattern('/users/:id', 'https://example.com');
pattern.test('https://example.com/users/123'); // true
pattern.test('https://example.com/posts/123'); // false

交互演示

模式：/users/:id (baseURL: https://example.com)

3. exec() 方法 - 执行匹配

返回匹配结果对象，包含捕获的组信息。不匹配时返回 null。

const pattern = new URLPattern('/users/:id', 'https://example.com');
const result = pattern.exec('https://example.com/users/123');
console.log(result.pathname.groups); // { id: '123' }
