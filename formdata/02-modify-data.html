FormData 事件 - 修改表单数据

formdata 事件的一个重要用途是在提交前修改表单数据。你可以：

  • 使用 set() 修改现有字段的值
  • 使用 delete() 删除不需要的字段
  • 对数据进行格式化和清理

用户注册表单

兴趣爱好（会合并为逗号分隔的字符串）

数据修改规则

  • username: 转换为小写
  • email: 去除首尾空格，转换为小写
  • phone: 去除所有空格和横线
  • password / confirmPassword: 删除，不发送到服务器
  • hobbies: 多个值合并为逗号分隔的字符串

关键代码

form.addEventListener('formdata', (event) => { const formData = event.formData; // 1. 修改字段值 - 用户名转小写 const username = formData.get('username'); formData.set('username', username.toLowerCase()); // 2. 格式化邮箱 const email = formData.get('email'); formData.set('email', email.trim().toLowerCase()); // 3. 清理手机号 const phone = formData.get('phone'); formData.set('phone', phone.replace(/[\s-]/g, '')); // 4. 删除敏感字段 formData.delete('password'); formData.delete('confirmPassword'); // 5. 合并多选值 const hobbies = formData.getAll('hobbies'); formData.delete('hobbies'); formData.set('hobbies', hobbies.join(',')); });
