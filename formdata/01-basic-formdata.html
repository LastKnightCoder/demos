FormData 事件 - 基础用法

formdata 事件在表单构造 FormData 对象时触发。通过监听此事件，可以在数据发送前查看或修改表单数据。

本示例演示如何监听 formdata 事件并查看 FormData 的内容。

关键代码

// 监听 formdata 事件 form.addEventListener('formdata', (event) => { // event.formData 包含表单的所有数据 const formData = event.formData; // 遍历 FormData 内容 for (const [key, value] of formData.entries()) { console.log(`${key}: ${value}`); } });
