FormData 事件 - 添加额外数据

formdata 事件的另一个重要用途是添加表单中不存在的额外数据。这些数据可以是：

  • 自动生成的数据（时间戳、UUID）
  • 计算得出的数据（字数统计、校验和）
  • 环境信息（浏览器、屏幕尺寸）
  • 业务相关的元数据

将自动添加的额外数据

字段名 说明 类型
timestamp 提交时的时间戳 自动
submitTime 格式化的提交时间 自动
contentLength 内容字符数 计算
wordCount 内容字数（中文按字，英文按词） 计算
userAgent 浏览器信息 元数据
screenSize 屏幕尺寸 元数据
language 浏览器语言 元数据
timezone 时区 元数据

反馈表单

表单只有 3 个字段：title, content, category

实际提交的数据（包含额外字段）

关键代码

form.addEventListener('formdata', (event) => { const formData = event.formData; // 添加时间戳 formData.append('timestamp', Date.now()); formData.append('submitTime', new Date().toISOString()); // 添加计算数据 const content = formData.get('content'); formData.append('contentLength', content.length); formData.append('wordCount', countWords(content)); // 添加环境信息 formData.append('userAgent', navigator.userAgent); formData.append('screenSize', `${screen.width}x${screen.height}`); formData.append('language', navigator.language); formData.append('timezone', Intl.DateTimeFormat().resolvedOptions().timeZone); });
