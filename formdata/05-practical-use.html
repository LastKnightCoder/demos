FormData 事件 - 实际应用场景

本示例展示 formdata 事件在实际开发中的应用场景：

  • 让自定义组件（星级评分、标签输入）参与表单提交
  • 处理富文本编辑器内容
  • 与 Fetch API 配合使用

场景 1：自定义组件参与表单 星级评分 + 标签输入

自定义的星级评分和标签输入组件没有原生的表单字段，通过 formdata 事件可以让它们的数据参与表单提交。

场景 2：富文本编辑器 contenteditable

使用 contenteditable 的富文本编辑器不是表单元素，需要通过 formdata 事件将其内容添加到表单数据中。

场景 3：与 Fetch API 配合 AJAX 提交

使用 formdata 事件修改数据后，通过 Fetch API 发送请求。这是现代 Web 应用中最常见的表单处理方式。
