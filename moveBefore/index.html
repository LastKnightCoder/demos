moveBefore API

原子移动 DOM 节点，保留所有内部状态

⚠️ 你的浏览器不支持 moveBefore（需要 Chrome 133+）。部分 demo 将使用 insertBefore 降级，你可以观察到状态丢失的现象。

Demo 1 · iframe 不重新加载

iframe 内嵌了一个每秒递增的计时器。用 insertBefore 移动后 iframe 会重新加载，计数归零； 用 moveBefore 移动后计时器继续运行。

Demo 3 · 焦点与选区保留

先在输入框中选中部分文字，再移动节点。 insertBefore 会导致焦点和选区完全丢失；moveBefore 保留焦点（元素仍是 activeElement，选区数据也在），但视觉光标需要再次交互才会显示——这是浏览器当前实现的已知限制，不是代码问题。

Demo 4 · Popover 不被关闭

先点击按钮打开 popover，再移动节点。 insertBefore 会导致 popover 关闭；moveBefore 保持其打开状态。

Demo 6 · 使用限制

moveBefore 要求被移动的节点必须已在页面中（isConnected === true）。 对未连接的节点调用会抛出错误，而 insertBefore 则没有此限制。
