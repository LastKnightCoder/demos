基础示例：扩展按钮元素

普通按钮 vs 自定义按钮

下面展示了普通按钮和使用 is 属性扩展的自定义按钮的区别：

点击次数: 0

代码说明

HTML 部分

<button is="fancy-button">自定义按钮</button>

JavaScript 部分

class FancyButton extends HTMLButtonElement {
  constructor() {
    super();
    this.clickCount = 0;
  }

  connectedCallback() {
    this.addEventListener('click', this.handleClick);
  }

  handleClick = () => {
    this.clickCount++;
    console.log(`按钮被点击了 ${this.clickCount} 次`);
  }
}

customElements.define('fancy-button', FancyButton, {
  extends: 'button'
});

关键点

  • 继承 HTMLButtonElement：保留了按钮的所有原生功能
  • 使用 extends 选项：告诉浏览器这是扩展的内置元素
  • connectedCallback：元素插入 DOM 时自动调用
  • 保留语义：屏幕阅读器仍然识别为按钮
