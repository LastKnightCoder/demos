📋 可展开详情元素

增强的 <details> 元素

使用 is="fancy-details" 扩展原生 <details> 元素，添加动画和统计功能：

什么是 HTML is 属性？

is 属性允许你创建自定义内置元素，扩展现有 HTML 元素的功能。

它的主要优势是：

  • 保留原生元素的所有功能和语义
  • 继承可访问性特性
  • 添加自定义行为和样式
浏览器兼容性如何？

自定义内置元素的浏览器支持情况：

  • ✅ Chrome/Edge 67+
  • ✅ Firefox 63+
  • ❌ Safari（不支持）

对于 Safari，可以使用 polyfill 或回退到自主自定义元素。

使用场景有哪些？

适合使用 is 属性的场景：

  • 增强按钮功能（如添加波纹效果）
  • 自动保存的表单输入
  • 带统计的可展开元素
  • 自定义列表项行为
注意事项

使用时需要注意：

  • Safari 不支持，需要考虑降级方案
  • 必须使用 extends 选项注册
  • 继承的类必须是对应的 HTML 元素类
  • 不能用于 void 元素（如 <img>）

实现原理

HTML 使用

<details is="fancy-details">
  <summary>标题</summary>
  <div class="content">
    内容...
  </div>
</details>

JavaScript 实现

class FancyDetails extends HTMLDetailsElement {
  connectedCallback() {
    this.addEventListener('toggle', this.handleToggle);
    this.wrapContent();
  }

  wrapContent() {
    // 将内容包装在 div 中以便添加动画
    const summary = this.querySelector('summary');
    const content = Array.from(this.childNodes)
      .filter(node => node !== summary);

    const wrapper = document.createElement('div');
    wrapper.className = 'content';
    content.forEach(node => wrapper.appendChild(node));
    this.appendChild(wrapper);
  }

  handleToggle = () => {
    // 统计打开/关闭次数
    if (this.open) {
      this.openTime = Date.now();
    } else {
      const duration = (Date.now() - this.openTime) / 1000;
      console.log(\`打开了 \${duration} 秒\`);
    }
  }
}

核心特性

  • ✅ 继承原生 <details> 的所有功能
  • ✅ 添加平滑的展开/收起动画
  • ✅ 统计打开次数和时长
  • ✅ 支持不同的主题样式
  • ✅ 保留键盘导航和可访问性
