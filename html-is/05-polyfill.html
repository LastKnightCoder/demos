两种实现方式对比

特性 自定义内置元素 (is) 自主自定义元素
HTML 写法 <button is="my-btn"> <my-button>
继承 继承原生元素 继承 HTMLElement
语义 保留原生语义 需要自定义
可访问性 自动继承 需要手动实现
Safari 支持 ❌ 不支持 ✅ 支持

推荐的兼容策略

方案 1: 特性检测 + 降级

// 检测浏览器支持
if ('customElements' in window &&
    document.createElement('button', {is: 'test'}).constructor !== HTMLUnknownElement) {
  // 使用自定义内置元素
  customElements.define('ripple-button', RippleButton, {extends: 'button'});
} else {
  // 降级到自主自定义元素
  customElements.define('ripple-button-fallback', RippleButtonFallback);
}

方案 2: 使用 Polyfill

<!-- 引入 polyfill -->
<script src="https://unpkg.com/@webcomponents/webcomponentsjs"></script>
<script src="https://unpkg.com/@webcomponents/custom-elements"></script>

方案 3: 只使用自主自定义元素

<!-- 放弃 is 属性，统一使用自主自定义元素 -->
<ripple-button>点击我</ripple-button>
