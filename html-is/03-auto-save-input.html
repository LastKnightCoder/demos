💾 自动保存输入框

实时自动保存表单

使用 is="auto-save-input" 扩展输入框，实现自动保存到 localStorage：

实现原理

HTML 使用

<input
  type="text"
  is="auto-save-input"
  data-save-key="username"
  placeholder="自动保存的输入框">

JavaScript 实现

class AutoSaveInput extends HTMLInputElement {
  connectedCallback() {
    this.saveKey = this.dataset.saveKey;
    this.loadSavedValue();
    this.addEventListener('input', this.handleInput);
  }

  loadSavedValue() {
    const saved = localStorage.getItem(this.saveKey);
    if (saved) this.value = saved;
  }

  handleInput = () => {
    clearTimeout(this.saveTimeout);
    this.showSaving();

    this.saveTimeout = setTimeout(() => {
      localStorage.setItem(this.saveKey, this.value);
      this.showSaved();
    }, 500);
  }
}

核心特性

  • ✅ 输入时自动保存到 localStorage
  • ✅ 防抖处理，避免频繁保存
  • ✅ 页面刷新后自动恢复数据
  • ✅ 视觉反馈显示保存状态
  • ✅ 支持 input 和 textarea
