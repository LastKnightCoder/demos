什么是 is 属性？

is 是 HTML 的全局属性，用于创建自定义内置元素（Customized Built-in Elements）。

它允许你扩展现有的 HTML 元素，为其添加自定义行为，同时保留原生元素的所有功能、语义和可访问性。

⚠️ 浏览器兼容性

  • ✅ Chrome/Edge 67+
  • ✅ Firefox 63+
  • ❌ Safari（不支持，需要使用降级方案）
