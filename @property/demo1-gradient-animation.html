@property 实现渐变动画

普通 CSS 无法对 gradient 进行过渡动画，但通过 @property 注册渐变中的各个参数，可以分别对角度、颜色进行平滑动画。

锥形渐变旋转

/* 关键：注册角度属性 */ @property --gradient-angle { syntax: "<angle>"; inherits: false; initial-value: 0deg; } /* 在渐变中使用注册的属性 */ .box { background: linear-gradient(var(--gradient-angle), red, blue); animation: rotate 3s linear infinite; } @keyframes rotate { to { --gradient-angle: 360deg; } }
