@property 继承行为对比

通过 inherits 描述符，可以精确控制自定义属性是否从父元素继承。 这在组件设计中非常重要——有时需要继承（如主题色），有时需要隔离（如组件内部变量）。

inherits: true 可继承

子元素自动获得父元素设置的值

父元素: --inherited-color: #10b981
子元素使用 var(--inherited-color)
子元素继承了父元素的绿色 ✓

inherits: false 不继承

子元素使用 initial-value，忽略父元素的值

父元素: --non-inherited-color: #10b981
子元素使用 var(--non-inherited-color)
子元素使用 initial-value (#6366f1)

字体大小继承 可继承

--inherited-size: 24px 在父元素设置

父元素设置 --inherited-size: 24px
这段文字使用继承的 24px 字号

字体大小不继承 不继承

--non-inherited-size: 24px 在父元素设置

父元素设置 --non-inherited-size: 24px
这段文字使用 initial-value 的 16px 字号

实际应用：组件样式隔离

使用 inherits: false 确保每个组件独立使用自己的主题变量，不受外层容器影响。

每个组件独立设置 --component-accent 和 --component-radius：

Alert 组件

accent: #ef4444, radius: 12px

Success 组件

accent: #10b981, radius: 16px

Info 组件

accent: #3b82f6, radius: 4px

外层容器设置了 --component-accent: #f59e0b，但由于 inherits: false，内部组件不受影响：

Alert 组件

仍然是红色，未继承父级的橙色

Default 组件

使用 initial-value (#6366f1)，也未继承橙色

何时选择 inherits: true vs false？

inherits: true 适用于：主题色、全局字体大小、间距单位等需要从根节点向下传递的设计令牌。类似原生 CSS 的 color、font-family。

inherits: false 适用于：组件内部的装饰属性（如边框颜色、圆角大小）、动画中间状态等不应泄露到子组件的局部变量。类似原生 CSS 的 border、background。
