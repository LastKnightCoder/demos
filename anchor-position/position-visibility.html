切换不同的 position-visibility 值，观察浮层在各种情况下的显隐行为

向上滚动，锚点消失，浮层隐藏
我跟着锚点显隐 ✦
向下滚动，锚点消失，浮层隐藏
浮层状态：显示中 锚点在容器视口内
position-visibility: anchors-visible;
/* 锚点元素滚出视口时，浮层自动隐藏 */
浮层溢出容器时我会消失 ✦
容器高度 200px
浮层状态：显示中 浮层未溢出容器
position-visibility: no-overflow;
/* 浮层超出其包含块时，自动隐藏 */
向上滚动，锚点消失，但浮层仍然显示
我始终显示 ✦
向下滚动，锚点消失，但浮层仍然显示
浮层状态：始终显示 锚点不可见时浮层不会自动隐藏
position-visibility: always;
/* 默认值，定位元素始终渲染，不受锚点可见性影响 */
