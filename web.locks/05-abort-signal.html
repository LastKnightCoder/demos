AbortSignal：超时与取消

通过 AbortController 或 AbortSignal.timeout() 取消等待中的锁请求。 注意：只能取消等待，不能取消已持有的锁。

前置条件：占用锁

先让一个"占位者"持有锁，这样后续的请求才会进入等待状态，才能演示取消功能。

代码示例
手动取消
const ac = new AbortController();

try {
  await navigator.locks.request(
    'resource',
    { signal: ac.signal },
    async () => { /* ... */ }
  );
} catch (err) {
  if (err.name === 'AbortError') {
    // 被手动取消
  }
}

// 取消等待：
ac.abort();
超时取消
try {
  await navigator.locks.request(
    'resource',
    {
      signal: AbortSignal.timeout(3000)
    },
    async () => { /* ... */ }
  );
} catch (err) {
  if (err.name === 'TimeoutError') {
    // 超时自动取消
  }
}
⚠️ 重要：AbortSignal 只能取消等待中的锁请求。 一旦回调开始执行（锁已持有），abort 信号不会中断正在运行的回调。 如果需要中断正在执行的操作，需要在回调内部自行检查 signal.aborted。
