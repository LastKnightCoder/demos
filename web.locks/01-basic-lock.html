基础锁获取与释放

观察 navigator.locks.request() 的基本行为：锁的获取、持有期间的状态、以及回调结束后的自动释放。

锁状态
🔓
"my-resource"
空闲（未持有）
控制
2000ms
等效代码
// 获取名为 "my-resource" 的独占锁
const result = await navigator.locks.request('my-resource', async (lock) => {
  // 此时独占持有该锁，其他请求必须等待
  console.log('持有锁：', lock.name, lock.mode);

  await sleep(2000); // 模拟异步操作

  return '操作完成'; // resolve → 锁自动释放
});

// 锁已释放，result === '操作完成'
💡 锁的持有时间由回调返回的 Promise 决定。Promise resolve 或 reject 时，锁立即自动释放，无需手动操作。 如果持有锁的标签页被关闭，锁也会自动释放，不会造成死锁。
